## 数据对象说明

### 1. DTO (Data Transfer Object) - 数据传输对象

用于**接收前端传来的数据**，通常在写入操作中使用。

| 类名 | 用途 | 字段 |
|------|------|------|
| `WaterReportDTO` | 上报水位入参 | stationId, waterLevel, recordedAt |
| `AlertHandleDTO` | 处理警报入参 | （本项目未单独定义，直接传ID） |

**位置**: `com.example.watermonitor.model.dto`

### 2. POJO (Plain Old Java Object) - 实体对象

与**数据库表一一对应**，用于各层之间传递数据。

| 类名 | 对应表 | 核心字段 |
|------|--------|----------|
| `Station` | station | id, name, location, warnLevel, dangerLevel, status |
| `WaterRecord` | water_record | id, stationId, waterLevel, recordedAt |
| `AlertRecord` | alert_record | id, stationId, recordId, alertType, status |

**位置**: `com.example.watermonitor.model.pojo`

### 3. VO (View Object) - 视图对象

用于**返回给前端**，通常比 POJO 多携带一些展示字段（如站点名称、枚举描述等）。

| 类名 | 用途 | 比 POJO 多出的字段 |
|------|------|-------------------|
| `StationVO` | 站点列表/详情展示 | - |
| `WaterRecordVO` | 水位记录展示 | stationName |
| `AlertRecordVO` | 警报记录展示 | stationName, alertTypeDesc, statusDesc |

**位置**: `com.example.watermonitor.model.vo`

## 各接口数据流转详情

### 一、监测站管理接口

#### 1. 获取所有站点列表 `GET /stations`

```
┌─────────┐     ┌─────────────────────────────────────────────────────────────┐
│  前端    │────→│  Controller                                                  │
│         │     │  StationController.getAllStations()                          │
│         │     │  ↓ 调用 stationService.getAllStations()                      │
└─────────┘     └─────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  Service                                                                     │
│  StationService.getAllStations()                                             │
│  ↓ 调用 stationDao.findAll()                                                 │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  DAO → Mapper → 数据库                                                        │
│  StationDao.findAll() → StationMapper.selectAll() → SELECT * FROM station    │
│  返回: List<Station> (POJO)                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓ (逐层返回)
┌─────────────────────────────────────────────────────────────────────────────┐
│  Controller 转换 POJO → VO                                                   │
│  List<Station> → convertToVO() → List<StationVO>                             │
│  ↓ 包装成 Result                                                             │
│  Result.success(voList)                                                      │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────┐     ┌─────────────────────────────────────────────────────────────┐
│  前端    │←────│  响应 JSON                                                   │
│         │     │  {code: 200, message: "success", data: [{...}, {...}]}       │
└─────────┘     └─────────────────────────────────────────────────────────────┘
```

**数据转换**: `Station (POJO)` → `StationVO`

---

#### 2. 获取单个站点 `GET /stations/{id}`

```
前端 ──→ Controller.getStationById(id) ──→ Service.getStationById(id) 
                                        ──→ DAO.findById(id) 
                                        ──→ Mapper.selectById(id) 
                                        ──→ 数据库
                                        
数据库 ──→ Mapper ──→ DAO ──→ Service (返回 Station POJO)
                                        ──→ Controller
                                        ──→ convertToVO(Station) → StationVO
                                        ──→ Result.success(vo)
                                        ──→ 前端
```

---

#### 3. 新增站点 `POST /stations`

```
前端发送 JSON: {name: "xxx", location: "xxx", warnLevel: 3.5, dangerLevel: 5.0}
                    ↓
Controller.addStation(@RequestBody Station station)
                    ↓
Service.addStation(Station POJO)
  ├─→ station.setStatus(1)  // 设置默认状态
  └─→ stationDao.save(station)  // 插入数据库
                    ↓
返回 Result.success() 给前端
```

**注意**: 此处直接使用了 POJO 接收参数，没有使用 DTO。

---

#### 4. 修改站点 `PUT /stations/{id}`

```
前端发送 JSON: {name: "新名称", warnLevel: 4.0}
                    ↓
Controller.updateStation(@PathVariable id, @RequestBody Station station)
  ├─→ station.setId(id)  // 把路径参数设置到对象中
  └─→ service.updateStation(station)
                    ↓
DAO.update(station) → Mapper.update() → UPDATE station SET ...
                    ↓
返回 Result.success()
```

---

#### 5. 停用站点 `DELETE /stations/{id}`

```
前端 ──→ DELETE /stations/1
           ↓
Controller.deleteStation(1)
           ↓
Service.disableStation(1)
           ↓
DAO.disable(1) → UPDATE station SET status=0 WHERE id=1
           ↓
返回 Result.success()
```

### 二、水位上报与查询接口

#### 1. 上报水位 `POST /water/report` ⭐核心接口

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  1. 前端请求                                                                  │
│  POST /water/report                                                           │
│  Body: {"stationId": 1, "waterLevel": 5.2, "recordedAt": "2026-03-30 10:00:00"} │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  2. Controller 接收并校验                                                     │
│  WaterRecordController.reportWaterLevel(@Valid @RequestBody WaterReportDTO)   │
│                                                                              │
│  @Valid 触发校验:                                                             │
│  - @NotNull: stationId 不能为空                                               │
│  - @NotNull + @Positive: waterLevel 必须为正数                                │
│                                                                              │
│  校验通过后，dto 包含:                                                         │
│  - stationId = 1                                                             │
│  - waterLevel = 5.2                                                          │
│  - recordedAt = LocalDateTime.parse("2026-03-30 10:00:00")                   │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  3. Service 处理业务逻辑 (@Transactional 事务)                                 │
│  WaterRecordService.reportWaterLevel(dto)                                    │
│                                                                              │
│  ┌─────────────────────────────────────────────────────────────────────────┐ │
│  │  3.1 校验站点存在性                                                      │ │
│  │  Station station = stationDao.findById(dto.getStationId())              │ │
│  │  if (station == null) throw new RuntimeException("监测站不存在")          │ │
│  │  if (station.getStatus() != 1) throw new RuntimeException("监测站已停用") │ │
│  └─────────────────────────────────────────────────────────────────────────┘ │
│                                    ↓                                         │
│  ┌─────────────────────────────────────────────────────────────────────────┐ │
│  │  3.2 DTO → POJO 转换                                                    │ │
│  │  WaterRecord record = new WaterRecord();                                │ │
│  │  record.setStationId(dto.getStationId());      // 1                     │ │
│  │  record.setWaterLevel(dto.getWaterLevel());    // 5.2                   │ │
│  │  record.setRecordedAt(dto.getRecordedAt());    // 时间对象               │ │
│  └─────────────────────────────────────────────────────────────────────────┘ │
│                                    ↓                                         │
│  ┌─────────────────────────────────────────────────────────────────────────┐ │
│  │  3.3 保存水位记录                                                        │ │
│  │  waterRecordDao.save(record) → INSERT INTO water_record ...             │ │
│  │  数据库返回生成的 id 设置到 record 对象中                                │ │
│  └─────────────────────────────────────────────────────────────────────────┘ │
│                                    ↓                                         │
│  ┌─────────────────────────────────────────────────────────────────────────┐ │
│  │  3.4 判断是否触发警报（业务核心逻辑）                                     │ │
│  │  BigDecimal waterLevel = dto.getWaterLevel();      // 5.2               │ │
│  │  BigDecimal dangerLevel = station.getDangerLevel(); // 例如 5.0         │ │
│  │  BigDecimal warnLevel = station.getWarnLevel();     // 例如 3.5         │ │
│  │                                                                          │ │
│  │  判断: 5.2 >= 5.0 → true → 触发危险警报                                   │ │
│  │  if (waterLevel >= dangerLevel) {                                       │ │
│  │      AlertRecord alert = new AlertRecord();                             │ │
│  │      alert.setStationId(station.getId());                               │ │
│  │      alert.setRecordId(record.getId());  // 刚刚插入的水位记录ID          │ │
│  │      alert.setAlertType(AlertType.DANGER.getCode());  // 2              │ │
│  │      alert.setWaterLevel(waterLevel);                                   │ │
│  │      alert.setStatus(0);                                                │ │
│  │      alertRecordDao.save(alert); → INSERT INTO alert_record ...         │ │
│  │  } else if (waterLevel >= warnLevel) {                                  │ │
│  │      // 触发警戒警报, alertType = 1                                     │ │
│  │  }                                                                      │ │
│  │  // 否则不触发警报                                                      │ │
│  └─────────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  4. Controller 返回结果                                                       │
│  return Result.success();  // code=200, message="success", data=null        │
└─────────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  5. 前端收到响应                                                              │
│  {code: 200, message: "success", data: null}                                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

**关键转换**: `WaterReportDTO (接收)` → `WaterRecord POJO (入库)` + `AlertRecord POJO (可能)`

#### 2. 查询历史水位 `GET /water/records`

```
前端请求: GET /water/records?stationId=1&startTime=2026-03-01 00:00:00&endTime=2026-03-30 23:59:59
                                   ↓
Controller.getRecords(stationId, startTime, endTime)
  ├─→ @DateTimeFormat 将字符串转成 LocalDateTime
  └─→ waterRecordService.getRecords(stationId, startTime, endTime)
                                   ↓
Service.getRecords(...) → DAO.findByStationIdAndTimeRange(...)
                                   ↓
Mapper.findByStationIdAndTimeRange() → SELECT ... FROM water_record WHERE ...
                                   ↓
返回: List<WaterRecord> (POJO列表)
                                   ↓ (逐层返回)
Controller 中:
  List<WaterRecordVO> voList = records.stream()
      .map(this::convertToVO)  // POJO → VO
      .collect(Collectors.toList());
                                   ↓
  convertToVO(record):
      WaterRecordVO vo = new WaterRecordVO();
      BeanUtils.copyProperties(record, vo);  // 复制基础字段
      Station station = stationService.getStationById(record.getStationId());
      vo.setStationName(station.getName());  // 补充站点名称
      return vo;
                                   ↓
返回 Result.success(voList)
```

**数据转换**: `WaterRecord (POJO)` → `WaterRecordVO (VO)` + 额外查询站点名称

### 三、警报管理接口

#### 1. 查询警报列表 `GET /alerts`

```
前端请求: GET /alerts 或 GET /alerts?status=0
                              ↓
Controller.getAlerts(status)
  └─→ alertRecordService.getAlerts(status)
                              ↓
DAO.findAll(status) → Mapper.selectAll(status) → SELECT * FROM alert_record WHERE ...
                              ↓
返回 List<AlertRecord> (POJO列表)
                              ↓
Controller 转换:
  records.stream().map(this::convertToVO).collect(...)
                              ↓
convertToVO(record):
  AlertRecordVO vo = new AlertRecordVO();
  BeanUtils.copyProperties(record, vo);
  
  // 补充站点名称
  Station station = stationService.getStationById(record.getStationId());
  vo.setStationName(station.getName());
  
  // 补充警报类型描述
  AlertType alertType = AlertType.of(record.getAlertType());
  vo.setAlertTypeDesc(alertType.getDesc());  // "警戒" 或 "危险"
  
  // 补充状态描述
  AlertStatus alertStatus = AlertStatus.of(record.getStatus());
  vo.setStatusDesc(alertStatus.getDesc());  // "未处理" 或 "已处理"
  
  return vo;
                              ↓
Result.success(voList)
```

**数据转换**: `AlertRecord (POJO)` → `AlertRecordVO (VO)` + 站点名称 + 枚举描述

---

#### 2. 处理警报 `PUT /alerts/{id}/handle`

```
前端 ──→ PUT /alerts/1/handle
           ↓
Controller.handleAlert(1)
           ↓
Service.handleAlert(1)
  ├─→ AlertRecord alert = alertRecordDao.findById(1);
  ├─→ if (alert == null) throw new RuntimeException("警报记录不存在");
  ├─→ if (alert.getStatus() == 1) throw new RuntimeException("该警报已处理");
  └─→ alertRecordDao.handle(1);  // UPDATE alert_record SET status=1, handled_at=NOW()
           ↓
返回 Result.success()
```

## 数据对象转换速查表

### 写入流程（前端 → 数据库）

| 接口 | 前端 JSON | Controller 接收 | Service 处理 | 入库对象 |
|------|-----------|-----------------|--------------|----------|
| POST /stations | Station 字段 | `Station` POJO | `Station` POJO | `Station` → station 表 |
| PUT /stations/{id} | Station 字段 | `Station` POJO | `Station` POJO | `Station` → station 表 |
| POST /water/report | stationId, waterLevel... | `WaterReportDTO` | `WaterRecord` POJO | `WaterRecord` → water_record 表 |
| PUT /alerts/{id}/handle | - | `Long id` | - | UPDATE alert_record 表 |

### 查询流程（数据库 → 前端）

| 接口 | 查询结果 | Service 返回 | Controller 转换 | 前端收到 |
|------|----------|--------------|-----------------|----------|
| GET /stations | `List<Station>` | `List<Station>` | `List<StationVO>` | StationVO 数组 |
| GET /stations/{id} | `Station` | `Station` | `StationVO` | StationVO |
| GET /water/records | `List<WaterRecord>` | `List<WaterRecord>` | `List<WaterRecordVO>` | WaterRecordVO 数组 |
| GET /water/latest/{id} | `WaterRecord` | `WaterRecord` | `WaterRecordVO` | WaterRecordVO |
| GET /alerts | `List<AlertRecord>` | `List<AlertRecord>` | `List<AlertRecordVO>` | AlertRecordVO 数组 |

## 总结

1. **Controller 层**: 负责接收 HTTP 请求、参数校验、DTO/VO 转换、返回统一响应
2. **Service 层**: 负责业务逻辑编排、数据转换（DTO→POJO）、事务控制、跨表操作协调
3. **DAO 层**: 负责数据访问封装，可组合多个 Mapper 完成复杂查询
4. **Mapper 层**: 负责单表 SQL 映射，与数据库直接交互
5. **数据流向**: 
   - 写入: DTO → POJO → 数据库
   - 查询: 数据库 → POJO → VO → 前端
